# 大學生課表與作業整合系統｜產品待辦清單（Product Backlog）

## 說明
- 格式：以使用者故事（User Story）撰寫，搭配驗收條件（Acceptance Criteria）。
- 優先級：P0（必做）／P1（應做）／P2（可做）。
- 狀態：To Do / In Progress / Done。

---

## Epic A｜課表與任務整合

### PB-001｜建立課表（手動）
- **優先級**：P0
- **狀態**：To Do
- **使用者故事**：
  - 身為一名大學生，我希望可以快速建立每週課表，讓我每天知道要上哪些課、在哪裡上課。
- **驗收條件**：
  1. 可新增課程名稱、星期、開始/結束時間、教室、教師。
  2. 同一時段重疊課程時，系統顯示衝突提示。
  3. 建立後可在週視圖正確顯示課程區塊。
  4. 使用者可在 10 分鐘內完成一週課表建立（可用性測試）。

### PB-002｜新增作業並關聯課程
- **優先級**：P0
- **狀態**：To Do
- **使用者故事**：
  - 身為一名大學生，我希望把作業直接綁定對應課程，避免資訊分散在不同工具。
- **驗收條件**：
  1. 可填寫作業名稱、截止日期時間、課程、備註。
  2. 作業可標記「未開始 / 進行中 / 已完成 / 已提交」。
  3. 新增流程不超過 3 個主要步驟。
  4. 課程頁面可看到該課全部作業清單。

### PB-003｜一鍵匯入課表（CSV/ICS）
- **優先級**：P2
- **狀態**：To Do
- **使用者故事**：
  - 身為新生，我希望能匯入既有課表檔案，減少手動輸入時間。
- **驗收條件**：
  1. 支援 CSV/ICS 檔案上傳。
  2. 匯入前可預覽欄位對應與資料筆數。
  3. 匯入失敗時顯示可理解錯誤訊息（含行號）。
  4. 匯入成功後，週視圖可立即呈現課程。

## Epic B｜提醒與優先排序

### PB-004｜截止提醒通知（D-7 / D-3 / D-1 / 當日）
- **優先級**：P0
- **狀態**：To Do
- **使用者故事**：
  - 身為一名容易忘記截止日的學生，我希望在不同時間點收到提醒，避免遲交。
- **驗收條件**：
  1. 可對每門課或每項作業設定提醒開關。
  2. 預設提供 D-7、D-3、D-1、當日提醒。
  3. 提醒可透過 App 推播顯示。
  4. 提醒送達率需達 95% 以上（測試環境基準）。

### PB-005｜待辦優先排序（基礎規則）
- **優先級**：P0
- **狀態**：To Do
- **使用者故事**：
  - 身為時間有限的學生，我希望系統幫我排出先做什麼，降低決策成本。
- **驗收條件**：
  1. 清單預設依「截止時間」由近到遠排序。
  2. 可額外設定重要度（高/中/低）並影響排序。
  3. 已完成或已提交項目預設移到清單底部。
  4. 使用者可切換「截止優先」與「重要度優先」兩種排序模式。

### PB-006｜智慧摘要通知
- **優先級**：P1
- **狀態**：To Do
- **使用者故事**：
  - 身為兼職學生，我希望通知只顯示最重要項目，避免資訊疲勞。
- **驗收條件**：
  1. 每日摘要只顯示當日與 48 小時內高優先任務。
  2. 相同任務不重複推播超過 1 次/日。
  3. 通知可直接點入任務詳情頁。
  4. 使用者可在設定中調整摘要時段。

## Epic C｜任務可視化與執行效率

### PB-007｜今日 / 本週總覽儀表板
- **優先級**：P0
- **狀態**：To Do
- **使用者故事**：
  - 身為忙碌的大學生，我希望打開系統就能知道今天課程與本週待交重點。
- **驗收條件**：
  1. 首頁顯示「今日課程」「今日到期」「本週待交」。
  2. 任務卡片包含課程、截止時間、狀態、優先級。
  3. 點擊任務卡片可進入編輯/完成操作。
  4. 使用者可在 5 秒內辨識最高優先任務（可用性測試）。

### PB-008｜空堂時段檢視
- **優先級**：P1
- **狀態**：To Do
- **使用者故事**：
  - 身為有打工與社團的學生，我希望系統標出可用空堂，方便安排讀書與小組討論。
- **驗收條件**：
  1. 可顯示每日空檔區間（例如 30 分鐘以上）。
  2. 可從空檔快速建立任務或讀書時段。
  3. 切換日/週視圖時資料一致。
  4. 空檔區間與課程時間不重疊。

### PB-009｜作業分類與標籤
- **優先級**：P1
- **狀態**：To Do
- **使用者故事**：
  - 身為同時有個人與小組作業的學生，我希望用標籤分類任務，快速聚焦。
- **驗收條件**：
  1. 支援分類：個人/小組、作業/報告/考試。
  2. 清單支援單一與多重篩選。
  3. 任務列表可顯示標籤並可編輯。
  4. 篩選結果可維持到下次開啟（記住偏好）。

### PB-010｜衝突偵測（課業 vs 打工/活動）
- **優先級**：P1
- **狀態**：To Do
- **使用者故事**：
  - 身為兼職學生，我希望系統自動提醒時間衝突，避免臨時調班與漏課。
- **驗收條件**：
  1. 新增事件時即時檢查時間重疊。
  2. 衝突事件以紅色標示，並顯示衝突對象。
  3. 提供「改期建議時段」或快速跳轉調整。
  4. 衝突解除後即恢復正常標示。

## Epic D｜回顧與成效

### PB-011｜每週回顧報告
- **優先級**：P1
- **狀態**：To Do
- **使用者故事**：
  - 身為重視成績與效率的學生，我希望每週看到完成率與延遲原因，持續調整策略。
- **驗收條件**：
  1. 顯示每週完成任務數、延遲件數、完成率。
  2. 可依課程查看完成表現。
  3. 報告可回看最近 8 週資料。
  4. 可匯出圖片或 PDF（選配）。

### PB-012｜壓力熱區預測
- **優先級**：P2
- **狀態**：To Do
- **使用者故事**：
  - 身為大四專題生，我希望提前看到高壓週，及早分配工作量。
- **驗收條件**：
  1. 顯示未來 2–4 週作業密度熱區。
  2. 高壓區定義可設定（例如每週 > N 件截止）。
  3. 高壓週前至少 7 天提醒。
  4. 可從熱區直接展開任務清單。

## Definition of Done（DoD）
每個待辦項目完成需符合：
1. 使用者故事與驗收條件全部通過。  
2. 關鍵流程可在手機版完成。  
3. 主要操作有錯誤提示與空狀態文案。  
4. 不影響既有 P0 功能穩定性。  
5. 文件已更新（欄位、流程、限制）。
